怎么拿快照

  1. 打开牌局页 bgacn.com/r/xxxxxx（要已进房间、牌发下来了，最好在「猜字」阶段）
  2. 按 F12 → 切到「控制台 / Console」
  3. 在控制台里手打下面这行（是打字不是粘贴，Chrome 才不拦），回车 → 整页 HTML 进剪贴板
  4. Esc 关控制台 → 回到本页粘进下面的框 → 点「解析快照」
copy(document.documentElement.outerHTML)

备选：Elements 面板右键最上面的 <html> → 复制 → 复制 outerHTML（别选 innerHTML）。
