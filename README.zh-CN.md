# 猜字解底 · 求解器

A self-contained word-game solver for **猜字解底** (guess the hidden character, then the central answer). No install, no network, no account — open the page and type.

**在线演示：** [GitHub Pages](https://c0sin3.github.io/caizi-jiedi/)

[English README](README.md)

## 它做什么

| 场景 | 输入 | 输出 |
| --- | --- | --- |
| ① 猜字 | 别人给的两个提示字 | 可能隐藏字，按可信度排序，附组词证据 |
| ② 出提示 | 自己的隐藏字 | 一组「唯一解」的提示字对，附证据词与竞争候选 |
| ③ 解底 | 公共字 + 各人的隐藏字 | 中央谜底候选 |

① 可以一次加多组，适合线下多人同桌时一边看一边算。

## 玩法背景

每人有一个隐藏字，要写两个能分别和它组词的提示字（例如隐藏字「节」，提示「奏」「环」→ 节奏、环节）。猜中别人的字，猜的人 +1、被猜中的人 +1；所以提示写得越「唯一」，别人越容易猜中你，双方都受益。每轮另有一个公共字和一个中央谜底，中央谜底要能和所有人的隐藏字、以及公共字组词，猜中 +3。

## 排序规则

- **候选**必须能与所有提示字组成双字词；先比「最弱的一个词频」（min），再比词频合计。
- 词频低于 30 的候选默认折叠，标为「生僻组合」——多数是词典里的冷僻搭配。
- ② 的推荐先排除「有真实对手」的组合，再按证据词的常用度排序；可切换为「更唯一优先」，把完全无竞争对手的组合排到最前。
- 提示字默认只取常用字（按字频前 2500），避免给出没人认得的偏字。

## 数据

词典来自 [jieba](https://github.com/fxsjy/jieba) 的双字词表（MIT License），共 114,134 条，含词频。整份词表内嵌在 `index.html` 里，页面完全离线可用，也可以直接当本地文件打开。

## 说明

- 单文件，无依赖，无追踪，不发任何请求。
- 候选只是「词库里说得通」的字，不保证是对方心里的那一个；判断仍要结合语境。
